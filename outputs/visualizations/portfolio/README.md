# Portfolio visuals

These browser-renderable SVGs are generated from the project datasets and documented benchmark results for use in the README, reports, and portfolio material.

- `01_class_imbalance.svg` — positive-class rate across Fraud DS1, Fraud DS2, and AML.
- `02_amount_distribution_fraud_vs_legit.svg` — transaction amount summary for legitimate vs fraudulent DS1 transactions.
- `03_fraud_rate_by_hour.svg` — observed fraud rate by transaction hour in DS1.
- `04_category_fraud_rate.svg` — highest observed fraud rates by merchant category in DS1.
- `05_aml_payment_format.svg` — AML transfer volume by payment format.
- `06_model_benchmark.svg` — documented initial out-of-time benchmark metrics.

PNG copies can be regenerated from the same analysis workflow for slides or reports; SVG is retained here because it renders directly on GitHub and stays sharp at any size.
